About Notes Management System

Organize your thoughts and manage your notes easily.

🎯 Our Objective

The main objective of this project is to provide a simple, user-friendly platform where users can create, view, update, and delete their personal notes securely.

🔑 Key Features

✅ User Registration
✅ Secure Login and Logout
✅ Create and Manage Personal Notes
✅ View All Saved Notes
✅ Update and Delete Notes
✅ Forgot Password and Password Reset
✅ MySQL Database Integration
✅ User-Specific Notes Management

🛠️ Technologies Used

HTML5 CSS3 Python Flask Framework MySQL Database Jinja2 Templates Flask Sessions

🚀 Our Mission

Our mission is to make note-taking simple, organized, and accessible through a web-based application. The system helps users keep their important information in one place and manage it whenever needed.
